## 🧩 Principais projetos

### 🚌 Sistema de Transporte Municipal

Sistema voltado para gerenciamento de transporte municipal.

**Tecnologias:**

`Django` `React` `PostgreSQL` `Docker` `Nginx`

Principais conceitos trabalhados:

* Autenticação e controle de acesso
* Múltiplos perfis de usuário
* QR Codes
* Rastreamento de veículos
* Auditoria
* Proteção de dados
* Arquitetura multi-tenant

---

### ⚔️ DisciplineRPG

Aplicação de produtividade e gerenciamento de hábitos utilizando conceitos de gamificação.

**Tecnologias:**

`React` `Node.js` `Express` `PostgreSQL` `Docker`

Funcionalidades incluem:

* Sistema de hábitos
* Streaks
* Metas
* Dashboard
* KPIs
* Progressão gamificada
* Estatísticas

---

### 🧠 CreativeStudio

Projeto experimental envolvendo **Inteligência Artificial e sistemas multiagentes** para auxiliar na criação de campanhas, mundos e conteúdos de RPG.

Áreas exploradas:

* Sistemas multiagentes
* Orquestração de LLMs
* Contexto compartilhado
* Engenharia de prompts
* Geração de conteúdo
* Knowledge Graphs
